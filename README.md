# Admin-YouR-Party-Rentals

Admin website and Python backend for YouR Party Rentals LLC.

## Run

```sh
python3 server.py
```

Open `http://localhost:3002/admin-gallery.html` and sign in with the configured admin credentials. Defaults are `admin` / `yourr-admin`; set `GALLERY_ADMIN_USERNAME`, `GALLERY_ADMIN_PASSWORD`, and `PORT` before deployment.

The admin page manages gallery images, business banking and notification settings, drop-off time slots, rental inventory, prices, and up to four public booking packages.
